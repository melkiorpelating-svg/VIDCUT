# 🎬 VIDCUT — Editor Video Sederhana

> **Cepat • Mudah • Gratis • 100% Offline • Tanpa Watermark**

VIDCUT adalah editor video lengkap yang berjalan langsung di browser — tidak perlu instalasi, tidak perlu internet, dan gratis untuk semua orang! 🎉

---

## ✨ FITUR LENGKAP

| Kategori | Fitur |
|---|---|
| ✂️ **Edit Dasar** | Potong, bagi, gabung, putar, susun ulang klip |
| 📐 **Format Video** | 9:16 (HP/TikTok), 16:9 (YouTube), 1:1 (Instagram), 4:5 (Reels) |
| 🎵 **Audio & Musik** | Tambah musik dari file, atur volume, ekstrak suara |
| ✍️ **Teks & Tulisan** | Tambah teks, pilih warna, posisi fleksibel |
| 🎨 **Efek & Filter** | Hitam putih, hangat, lebih terang, kontras |
| ⚡ **Kecepatan** | Lambat 0.5x — Normal 1x — Cepat 2x |
| 📤 **Ekspor** | Simpan sebagai MP4, kualitas 720p / 1080p |
| 🖥️ **Tampilan** | Desktop & HP — otomatis menyesuaikan layar |
| 🔒 **Offline** | Semua proses di perangkat — tidak butuh internet! |

## 🚀 CARA PAKAI — SANGAT MUDAH!

### 📱 Cara 1: Langsung Buka (Tanpa Instalasi)
1. **Unduh file `index.html`** dari repositori ini → klik tombol ⬇️ **Code** → **Download ZIP**
2. Ekstrak file ZIP → cari file bernama **`index.html`**
3. **Klik dua kali** atau buka pakai browser (Chrome, Firefox, Edge, dll.)
4. ✅ Selesai! Langsung mulai mengedit video! 🎬

### 💻 Cara 2: Dari GitHub
1. Buka halaman file **`index.html`** di atas
2. Klik tombol **⋮** (tiga titik) → **Download file**
3. Simpan di perangkatmu
4. Buka dengan browser → mulai edit!

### 🌐 Cara 3: Lewat Website (jika sudah di-deploy)
- Buka alamat websitenya → langsung pakai tanpa unduh file! ✅

## 📖 PANDUAN PENGGUNAAN

### 📂 Menambahkan Video
- Klik area **"+ Tambah Video"** → pilih video dari perangkatmu
- Atau **tarik & lepas** video ke area tersebut

### ✂️ Memotong Video
1. Masuk ke tab **✂️ Potong**
2. Isi waktu mulai & waktu akhir (dalam detik)
3. Klik **Terapkan Potongan**

### 🎵 Menambah Musik
- Klik area **"+ Tambah Musik/Audio"** → pilih file musik
- Atur volume di bagian bawah pemutar

### ✍️ Menambah Teks
1. Masuk ke tab **✍️ Teks**
2. Ketik teks yang diinginkan
3. Pilih warna teks
4. Klik **Tambahkan Teks**

### 🎨 Menggunakan Filter
1. Masuk ke tab **🎨 Filter**
2. Pilih efek yang diinginkan
3. Klik **Terapkan**

### ⚡ Mengubah Kecepatan
1. Masuk ke tab **⚡ Kecepatan**
2. Geser slider untuk mengatur kecepatan (0.5x — 2x)
3. Klik **Terapkan**

### 📤 Menyimpan Hasil
- Klik tombol **📤 Ekspor Video** di pojok kanan atas
- Tunggu proses selesai → otomatis tersimpan di perangkatmu! ✅
